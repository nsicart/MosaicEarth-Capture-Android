# Security

For private vulnerability reports, use private vulnerability reporting on the GitHub repository when available, or contact `hello@mosaicearth.app`. Avoid including real customer imagery, private geospatial datasets or credentials in reports. Include the source revision, Android OS version, device model and a synthetic reproduction.

Local capture and on-device reconstruction store files inside Android's private application directory and do not transmit data over the network unless you explicitly sign in and start a MyEarth upload or MosaicEarth Cloud job.
