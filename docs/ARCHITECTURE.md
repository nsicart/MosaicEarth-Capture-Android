# Architecture

MosaicEarth Capture is a single-module Kotlin / Jetpack Compose / C++17 Android application (`app.mosaicearth.capture`) structured into clear domain packages:

- **`capture/`**: CameraX preview, non-blocking burst `ImageCapture`, continuous `VideoCapture` and real-time `ImageAnalysis` overlap estimation (`OverlapAnalyzer`) using normalized cross-correlation over downsampled luminance grids to report live frame-to-frame overlap and movement guidance.
- **`photogrammetry/` & `app/src/main/cpp/`**: foreground service (`PhotogrammetryService`) driving the native C++17 + OpenCV NDK reconstruction engine (`mosaicearth_photogrammetry`). Runs incremental Structure-from-Motion (RootSIFT descriptors, five-point essential-matrix RANSAC, incremental PnP registration, sparse Schur bundle adjustment, and EXIF GPS WGS84 ENU metric alignment), followed by rectified semi-global dense stereo matching, colored `.ply` point cloud fusion, `.glb` textured mesh generation, and DSM / true-orthophoto GeoTIFF export.
- **`local_training/`**: calibrates unposed image sets via the native SfM stage, exports a COLMAP `PINHOLE` scene (`cameras.txt`, `images.txt`, `points3D.txt`), and invokes the **Brush** Vulkan compute engine inside a dedicated `:brush` Android process (`BrushTrainingService`) so heavy GPU memory usage never destabilizes the main UI or database process. Devices without Vulkan compute support fall back cleanly to calibrated Surfel Gaussian `.ply` generation.
- **`viewer/` & `viewer-web/`**: embedded offline WebGL viewer (`Three.js` + `GaussianSplats3D`) served over a local loopback HTTP range bridge (`127.0.0.1`) from Android's private storage directory, supporting `.ply`, `.splat`, `.spz`, `.glb` and GeoTIFF rasters without CORS or WebWorker restrictions.
- **`projects/` & `quality/`**: Room SQLite persistence (`CaptureDatabase`) and private storage management (`CaptureStorage`), plus blur/duplicate sharpness inspection (`Quality.kt`) and video frame extraction.
- **`authentication/` & `cloud_processing/`**: optional MosaicEarth session client (`CloudApi`) and resumable WorkManager upload/job workers (`CloudWorker`) implementing `contracts/capture-v1.openapi.yaml` with 4 MiB SHA-256 verified chunks. Free local-model uploads (`priceEur = 0.0`) transfer finished `.ply`, `.glb` and `.tif` outputs into the user's private MyEarth workspace; raw capture uploads can optionally request cloud `NodeODX` or `COLMAP + OpenSplat` processing.
